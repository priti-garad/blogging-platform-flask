
# Blogging Platform Using Python Flask

## DIY Internship Project

**Author:** Priti Garad

## Project Description

This project is a simple Blogging Platform developed using Python Flask.

Users can register, login, create blog posts and view published blogs.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
- GitHub

## Features

1. User Registration
2. User Login and Logout
3. Create Blog Posts
4. View Published Posts
5. Store User Data in SQLite
6. Password Hashing

## Installation Steps

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.

Install required packages:

pip install -r requirements.txt

Run the application:

python app.py

Open your browser and visit:

http://127.0.0.1:5000/

## Conclusion

This project demonstrates the development of a basic web-based Blogging Platform using Python Flask, HTML, CSS and SQLite.
